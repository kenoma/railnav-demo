# railnav-demo — георадарная навигация на железной дороге

Демонстрационный проект к статье **«Георадарная система навигации
подвижного состава…»** : реализация
**Алгоритма 1** рекуррентного сопоставления проезда с картографическим
графом и **построения/обновления графа из истории проездов** (динамическое
программирование Витерби по графу гипотез).

Все данные **синтетические**: сеть генерируется процедурно, «георадар» —
симулятор с шумом одометра, пропусками и ложными сработками.

## Установка

```bash
cd railnav-demo
python3 -m pip install -e .        # зависимости: numpy, pandas, scipy, matplotlib, plotly
```

## Пакет (`src/railnav/`)

* `graph.py` — объект-узел `G_ij` = **пара** последовательных участков;
  разреженная `A_G`; маршруты стрелок (`connect`, `connect_switch`);
  `paper_example()` воспроизводит формулу (5) (8 узлов, 8 переходов);
* `model.py` — `mu = mu_symm · mu_dist · mu_emb` (формулы (6)–(7)),
  `MuParams` с переключением компонентов;
* `localizer.py` — Алгоритм 1: `x_{k+1} = A_Gᵀ [x̃_k ⊙ m_k]`, вывод позиции
  преобразованием `T(K_j, s^c)`, трасса `trace` по шагам;
* `map_updater.py` — слои гипотез `new / match / merge / pend`, весовой фильтр
  (`nu_new`, `nu_penalty`), маржинальный критерий `Δ > nu_margin`, режимы
  `strict / balanced / radical`, лог аномалий, мутация карты при одобрении;
* `synth.py` — `station_example`, `random_network`, `simulate_drive`
  (шум одометра, пропуски/ложные сработки, зашумлённые эмбеддинги);
* `metrics.py` — кривые идентификации при холодном старте;
* `viz.py` — matplotlib-схемы и анимация, plotly-исследования.

## Отличия от статьи (осознанные упрощения)

1. **Цепь второго порядка → первое порядка.** Витерби-построение карты
   работает на состояниях «направленное ребро + точка входа»
   (т. е. том же узле `G_ij`, что и Алгоритм 1), а не на парах рёбер:
   запрет разворота `k ≠ i` обеспечивается локально.
2. **`PEND` с одним накопителем.** Серия ложных сработок склеивается
   аддитивным остатком `carry`; альтернативная разбивка интервала не
   перебирается.
3. **`dominance_tol`** — «доминирующий» кандидат: `x > Θ` **и**
   `x ≥ 0.9·max`. Без допуска шум эмбеддингов и штраф `φ` создают
   ложные вторые моды на истинном маршруте.
4. **`delta_a_rel`** — шум одометра мультипликативный, поэтому эффективная
   ширина колокола `δ_a = max(δ_a, δ_a_rel·L)`.
5. **Эмбеддинги эмулируются** единичными векторами (один объект =
   зашумлённые дубликаты, разные ≈ ортогональны); сиамская сеть ResNet-18
   в статье обучается на реальных снимках балластной призмы.
6. Холодный старт `x_0` инициализируется по **первой паре** наблюдений
   (первое — частичное, `s ≤ L + 3δa`), что соответствует требованию
   статьи об идентификации «по последовательности сработок».
